# Desktop_pet 产品要求

面向少数朋友，从 GitHub 获取后在本地部署。开发以 Windows 为主，目标系统为 Windows 和 macOS。近期优先离线、本地和低成本；使用付费 API 或设置自动备用路径需要用户相应授权。商业推广和应用商店上架不在近期目标内。

## 橘猫与人格

最终橘猫形象以用户后续提供的参考为准。性格、说话习惯和行为方式应能体现用户调教；由用户用真实表达和新场景验证实际效果。核心人格按版本发布，每位朋友独立保存聊天及私人记忆。朋友的对话不会自动改写发布人格。

## M0 原型

M0 是创作者的离线人格验证工作台。界面提供草稿编辑、手动修正、人格版本发布、按朋友试聊、记忆管理和评估记录。初始样例为虚构开发素材。源码中各项职责如下。

| 模块 | 职责 |
| --- | --- |
| `src/renderer`、`src/preload` | Vue 工作台和通往主进程的受限接口 |
| `src/main/index.ts`、`src/shared/contracts.ts` | Electron 窗口、系统文件对话框、IPC 和共享接口 |
| `packages/persona-core` | 人格草稿和快照、记忆作用域、提示与评估场景 |
| `packages/local-model` | 连接本机 Ollama，校验本地模型、指纹与请求参数 |
| `src/main/service.ts`、`store.ts`、`bundle.ts` | 编排试聊与发布，保存本机 SQLite 数据，限制角色导出字段 |

本地明文数据库默认为 Electron 用户数据目录里的 `orange-cat-lab.sqlite`。角色包包含发布人格与模型配置；私人评估导出另行保存。备份时退出工作台，复制数据目录。初始化只迁移源码。

## 验收背景

用户此前报告的开发机为 Windows x64、i7-11800H、16 GB、RTX 3070 Laptop 8 GB。朋友使用 MacBook Pro 13 英寸，芯片和内存待确认。实际验收时重新核对系统、硬件、模型和参数。Windows 与 Mac 分别记录运行、安装和断网体验；语言风格与行为须有真实模型和用户体验依据。

旧包中的[验收项目](M0-ACCEPTANCE.md)与[分发说明](DISTRIBUTION.md)保留为基线材料。其路线设想以未来获批的版本方案为实施依据。
