# BOOTSTRAP 计划 · r1

## 目标与授权

在 Desktop_pet 建立三会话协作资料，逐文件迁移用户已有的橘猫 M0 原型，向 Work 交付可复核的初始化提交。基线为通过 SHA-256 核对的 `orange-cat-desktop-M0-v0.1.0.zip` 中的 `orange-cat-desktop/`。

授权依据为 2026-11-19 本次 Codex 会话用户首条任务消息第八节。原文为“本消息授权你执行 BOOTSTRAP 初始化：核对环境、建立规则、迁移已有原型、必要检查、提交和推送。”第六步明确授权在本地与远程均无提交时首次推送到 main，状态为“初始化待审核”。r1 整理该消息已确定的范围。用户对迁移结果的验收与 Work 的审核均待后续记录。
